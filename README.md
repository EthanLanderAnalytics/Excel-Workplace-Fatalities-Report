## Project Overview
This project uses Microsoft Excel to analyze a dataset containing workplace fatality data from 2012, to identify trends, safety insights, and relevant data as it pertains to business decision-making.

## Objective
- Clean and structure raw data to ensure accuracy and consistency
- Explore relationships between variables using Excel analysis tools
- Summarize insights in a clear, understandable format

## Tools Used
- Microsoft Excel (PivotTables, Charts, Formulas, Slicers)

## Analysis Performed
- Cleaned raw data, including creating state names from combined fields and handling missing values
- Explored relationships between inspection frequency, program type, and fatality rates using pivot tables and scatter plots
- Created histograms, column charts, and summary tables to visualize trends and highlight patterns
- Applied color scales and slicers to make the data easy to interpret for all audiences

## Key Insights
- Most states had low fatality rates, with a few high-rate outliers
- Inspection frequency did not show a clear relationship with fatality rates
- California had the highest number of injuries/illnesses among state programs
- Federal programs exhibited higher average fatality rates than state programs
- Data cleaning revealed inconsistencies that could impact reporting and future analyses

## Deliverables
- Cleaned and structured Excel dataset
- Pivot tables, charts, and summary tables highlighting trends and performance insights
- Insights summarized for both technical and non-technical stakeholders
